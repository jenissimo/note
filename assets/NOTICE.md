# Third-party definitions

note ships converted copies of two open packs.  Both are MIT licensed across
the whole repository, so every file below carries that licence.  The font at
the bottom of this file is under the SIL Open Font License instead.

## Themes -- `assets/themes/*.theme`

Converted from the base16 schemes collected by **tinted-theming/schemes**.
<https://github.com/tinted-theming/schemes> -- MIT.
Individual palettes name their own authors in a comment at the top of each
converted file.

## Syntax -- `assets/syntax/*.syntax`

Converted from the syntax files of **micro**, by Zachary Yedidia and
contributors.  <https://github.com/zyedidia/micro> -- MIT.

The conversion is lossy by design.  micro describes languages with regular
expressions; note's lexer has no regex engine and works from keyword lists and
delimiters, so the converter keeps the word lists, comment and string
delimiters and the preprocessor flag, and drops operator patterns, number
formats, nested rules and embedded sublanguages.

Regenerate both with:

    python tools/import_packs.py --fetch

## Font -- `src/platform/console/font_terminus.h`

The MS-DOS build can replace the VGA character generator at runtime, so the
font is a 4 KB table of 256 glyphs of 16 scanlines, generated by
`tools/font_to_c.py` and committed rather than fetched at build time.

**Terminus** -- `font_terminus.h`, from `ter-u16n.bdf` of terminus-font 4.49.1.
<https://sourceforge.net/projects/terminus-font/> -- SIL Open Font License 1.1,
which permits embedding without conditions beyond keeping this notice. The BDF
is Unicode-encoded and the converter reindexes it into code page 437; 32 of the
256 positions have no glyph in Terminus and come out blank, all of them in the
0x01-0x1F range DOS fills with symbols like the smiley faces, which a text
editor never draws.

Regenerate it with, for example:

    python tools/font_to_c.py ter-u16n.bdf src/platform/console/font_terminus.h ^
        --name kFontTerminus --note "Terminus 4.49.1 (ter-u16n), SIL OFL 1.1"
